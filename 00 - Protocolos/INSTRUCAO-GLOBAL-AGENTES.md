**LEIA ISTO ANTES DE QUALQUER TAREFA.**

Este diretório é a **Memória Central Compartilhada**.
- No Windows: `D:/cofreobsidiannotepaula` (ou caminho local configurado)
- No Linux/Servidor: `~/Documents/Obsidian Vault`
- Repositório Git: `git@github.com:Alexbsbb/obsidian-vault.git`

## Regras Obrigatórias para Todos os Agentes:

1. **Idioma Obrigatório:**
   - Sempre converse e responda no idioma do usuário (**Português do Brasil**).

2. **Sincronização Git (Início da Tarefa):**
   - Antes de consultar ou ler notas e memórias, execute `git pull origin main` (se tiver acesso a terminal) para garantir acesso à versão mais recente sincronizada entre todas as máquinas/agentes.

3. **Consultar Antes de Agir:**
   - Sempre busque aqui (`search_files`) por contextos relacionados à tarefa atual antes de gerar código ou soluções.

4. **Salvar Automaticamente e Sincronizar Git (Fim da Tarefa):**
   - Ao concluir uma etapa técnica ou gerar conhecimento significativo, salve o progresso em `00 - Protocolos/Handoff-Entre-Agentes.md` ou crie/atualize a nota temática em `Memórias/` ou `Skills/`.
   - Logo após salvar, execute `git add .`, realize um commit descritivo e faça `git push origin main`.

5. **Não Alucine Contexto:**
   - Se não está registrado aqui, considere desconhecido. Não invente histórico de conversas passadas.

6. **Formato Padrão:**
   - Use Markdown com frontmatter (`tags`, `data`) para todas as novas notas.
